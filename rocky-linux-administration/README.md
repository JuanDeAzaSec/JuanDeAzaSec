# Rocky Linux Administration

Documentación técnica, laboratorios prácticos y procedimientos de administración sobre Rocky Linux 9 (RHEL-based).

## Áreas de Implementación
- Administración de almacenamiento (LVM y sistemas de archivos).
- Gestión de servicios del sistema mediante `systemd`.
- Control de usuarios, grupos y políticas de permisos.
- Configuración básica de red y hardening de accesos.
