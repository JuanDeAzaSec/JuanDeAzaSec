# Cisco Networking Labs

Laboratorios y documentación de diseño, configuración y resolución de problemas de redes (ruta oficial CCNA).

## Áreas de Implementación
- Subnetting y direccionamiento IPv4/IPv6 mediante VLSM.
- Conmutación Capa 2: Segmentación por VLANs y enlaces troncales (802.1Q).
- Enrutamiento estático y verificación de conectividad extremo a extremo.
- Topologías prácticas implementadas en Cisco Packet Tracer.
